THE CONCEPT

A WORLD INSIDE THE UNKNOWN.

Hidden Dimensions is a mobile puzzle game built around a tesseract-inspired object containing eleven distinct sections. Each section represents a different dimension waiting to be explored.

Each dimension has its own color outline, allowing the player to recognize which dimension they are currently in.

Cuneiform and other ancient writing systems become part of the game's visual language and the puzzles themselves.

The overall puzzle system is intentionally broad at this stage. The goal is to create something mysterious that encourages the player to discover how the dimensions, symbols and puzzles connect.
